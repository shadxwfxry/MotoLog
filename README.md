# 🏍️ MotoLog v1.0

MotoLog is a modern, high-performance Progressive Web Application (PWA) designed for motorcycle enthusiasts to track maintenance, fuel expenses, and garage inventory. Integrated with Google Gemini AI for smart assistance.

<a name="english"></a>
## 🇬🇧 English

### Key Features
- **Smart Garage**: Manage multiple vehicles with photos and technical specs.
- **PWA Ready**: Install on iOS/Android for a native mobile experience.
- **MotoAssistant**: AI powered by Google Gemini (Flash) with web-search capabilities for technical advice.
- **Maintenance Log**: Track oil changes, tires, and repairs with recurring reminders.
- **Fuel Tracking**: Detailed statistics on consumption and fuel costs.
- **Multilingual Support**: Fully localized in EN, RU, and UK.

### Installation
1. Clone the repository.
2. Install dependencies: `npm install`
3. Set up `.env` file (see `.env.example`).
4. Run migrations: `npx prisma db push`
5. Start dev server: `npm run dev`

<a name="русский"></a>
## 🇷🇺 Русский

### Основные возможности
- **Умный гараж**: Управляйте своей техникой, добавляйте фото и технические характеристики.
- **PWA**: Установка на главный экран смартфона для работы в режиме "нативного" приложения.
- **MotoAssistant**: ИИ-помощник на базе Google Gemini (Flash) с доступом к поиску в реальном времени.
- **Журнал обслуживания**: Учет замен масла, запчастей и ремонтов с напоминаниями.
- **Учет топлива**: Подробная статистика расхода и затрат на бензин.
- **Мультиязычность**: Полная поддержка русского, украинского и английского языков.

### Установка
1. Клонируйте репозиторий.
2. Установите зависимости: `npm install`
3. Настройте `.env` (используйте `.env.example` как шаблон).
4. Примените схему БД: `npx prisma db push`
5. Запуск: `npm run dev`

## 🇺🇦 Українська

### Основні можливості
- **Розумний гараж**: Керуйте своєю технікою, додавайте фото та технічні характеристики.
- **PWA**: Встановлення на головний екран смартфона для роботи в режимі "нативного" додатка.
- **MotoAssistant**: ШІ-помічник на базі Google Gemini (Flash) з доступом до пошуку в реальному часі.

- **Облік палива**: Детальна статистика витрат та вартості пального.
- **Мультимовність**: Повна підтримка української, англійської та російської мов.

### Встановлення
1. Клонуйте репозиторій.
2. Встановіть залежності: `npm install`
3. Налаштуйте `.env` (використовуйте `.env.example`).
4. Застосуйте схему БД: `npx prisma db push`
5. Запуск: `npm run dev`

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Database**: PostgreSQL (Prisma ORM)
- **AI**: Google Generative AI (Gemini Flash)
- **Auth**: NextAuth.js
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
